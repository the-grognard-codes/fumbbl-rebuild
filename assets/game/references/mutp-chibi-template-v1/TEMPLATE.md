# MUTP mole and chibi artwork template

Reusable reference kit requested by the owner. This is a repository art template, not an installed Template Gallery skill. The original seven images are approved style references; mole medic/referee alternatives await visual selection.

## References
Use images/kick.png and images/receive.png for the painted mole character identity: dark navy fur, warm brown muzzle/nose, round gold glasses and bright blue eyes, ivory claws, charming compact proportions. Use references/site-mole.png for original brand identity and references/ui-atlas.png for the existing painted UI palette/materials. These are supporting references, not instructions to reproduce their background or unrelated objects.

The images directory retains heads, tails, kick, receive, stretcher, referee, shrug, mole-stretcher and mole-referee PNGs. Original goblin versions remain available. prompts.json stores the complete exact text and reference order used for each generation, including the new edit variants. Some original subject prompts said fantasy player/coach; the approved resulting mole identity is authoritative for later mole artwork.

## Reusable prompt
Create one transparent-background MUTP game UI icon showing [SUBJECT] performing [ACTION], with [ESSENTIAL OBJECTS]. Match the supplied approved character references: [SPECIES/IDENTITY]. Polished hand-painted fantasy game illustration, chibi proportions, strong dark outlines, readable silhouette at 64px. Existing navy, ivory, gold, leather brown and cyan palette. Single isolated subject or group filling the canvas with clear margin. No shield framing, labels, backdrop, floor or baked shadow; coin rims only when requested. Preserve transparent alpha.

For revisions, identify the edit target and supporting identity references separately. Specify what changes and what remains, particularly pose, expression, costume, palette and composition. Keep approved source images intact and save new variants separately. Reuse exact existing inducement art or player portraits when those are requested rather than regenerating them.

## Review
Inspect full-size artwork and the intended 64-84px UI presentation. Confirm species, expressive action, silhouette, transparent background and unclipped anatomy. Tail coins must have an unmistakable visible tail. Medic groups need two carriers and a readable stretcher/patient. This kit is for UI illustrations; it does not replace the separate team-player sprite standard.
