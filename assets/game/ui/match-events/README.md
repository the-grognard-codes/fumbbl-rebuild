# Match event emblems

Original MUTP geometric pixel emblems, authored for issue #565. 32×32 SVGs
with crisp edges; contain no text and no third-party art. Whistle is shared by
half-time and full-time; kick-off uses a ball emblem. Existing weather sprites
are reused from `../weather/`. The CSS ribbon and backdrop use team colour ramps.

Burst and weather masks are small shared geometric pixel assets. CSS tints them from the team/condition ramps and animates only transform/opacity. No text or per-team bitmap variants are embedded.
