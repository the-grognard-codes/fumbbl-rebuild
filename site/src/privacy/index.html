Current scope

The public site does not use analytics cookies. When sign-in is enabled, Firebase Authentication creates and manages an account only within the Firebase project for this domain. The browser-client development experience may connect only to the game service selected by its local development configuration.

Environment separation

Development and production use separate Firebase projects, provider registrations, user stores, and sessions. Existing FUMBBL accounts are outside this project and are not read, linked, changed, or migrated by this site.
