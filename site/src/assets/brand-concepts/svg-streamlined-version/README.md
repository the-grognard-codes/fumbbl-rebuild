# Moles Under the Pitch brand assets

These are original, editable SVG masters and their transparent PNG exports.
All deliberate fills and strokes use only the approved palette:
`#070d16`, `#101c2b`, `#2f7d32`, `#1c5a32`, `#4db2ff`, `#ffe17b`, `#874a2d`, and `#edf5ff`.

The logo SVGs reserve clear space in their source comments: 32 viewBox units for the wide lockup and 24 for the compact lockup. The mark reserves 16 units. Do not add content inside that space.

`moles-under-the-pitch-mark.svg` is the source for the OAuth, email, and app-mark PNG exports. `magic-link-complete-illustration.svg` is intentionally wordless so that the surrounding sign-in state provides accessible, localised text.

The lockups embed a relative reference to the included `fonts/chakra-petch-700.ttf` (Chakra Petch Bold, by Cadson Demak, licensed under the SIL Open Font License 1.1). This is an open, non-proprietary display face selected to preserve the approved chunky, chamfered wordmark treatment when assets are rendered outside the site stylesheet.
