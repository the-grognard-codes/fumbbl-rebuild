# M5e match presentation checkpoint — 2026-09-25

The hosted `/play/match` page now presents the authoritative home/away score, half, drive, turns, rerolls, weather, phase, selected player's identity/state/location, and all off-pitch players from the current projection. The current server-issued action is pinned before the same Commit/Space handler sends it. End Turn is a shortcut to pin the server's `endTurn` action, not a separate command or client-generated decision. Existing setup, kickoff, coin/receive, save/resume and other issued action controls remain available. No local preview odds, chat, guessed casualty/KO counts, or generated result is rendered.

Participant-only `matchResult.load` and `matchResult.replay` now pass through `/browser/v2` with the existing R2 result/authorization service and strict browser decoder. `/play/result?matchId=<uuid>` loads the durable final score and one replay event at a time; direct sign-in return/reload remains constrained to the same-site validated match ID. The replay pitch is read-only. The v2 envelope is newly declared and tested; its nested stored result and replay format remain version 1. A paired game-server/browser rollout is required; no database schema change is needed.

One-step target connectors chase decoratively, and player markers transition between server coordinates. Both effects stop under reduced-motion preference. They do not issue actions, change phase, or claim an unprovided multi-square path or success probability.

## Contract review and carried checks

- Live `/browser/v2` state has no event-summary list. Recorded replay events become available only after durable completion, and its current API is member-only. Putting snapshots into every live projection would duplicate large state and risk response limits; a separate bounded, versioned public event-summary contract with role review is required before a live log or spectator replay. M5e therefore displays the available completed history only to participants.
- A player with null coordinates is only known to be off pitch. The server does not distinguish reserve, KO, casualty, or sent-off categories in this projection; the panel says **Off pitch** and shows the server state text. Adding exact dugout categories requires a structured versioned field and audience tests.
- Player attributes/skills, other resources and success percentages are absent from the live contract. The authoritative percentage work is tracked in `TODO.md`. Static sprites and pitch art still require the R6 public-use disposition. Firefox, Safari/iPad, actual assistive-technology observations, human visual review and full integrated release checks remain open.
