# M6 BB2025 core skills and traits

Source: [Blood Bowl Base Skills & Traits](https://bloodbowlbase.ru/bb2025/core_rules/skills_and_traits/), checked 2026-09-25. The table contains twelve skills in each of Agility, Devious, General, Mutation, Passing and Strength, plus 36 traits: 108 entries. The source marks Block, Dodge, Guard and Mighty Blow as Elite. Stable IDs, names, categories and Elite flags are in [SkillDefinitions](../../ffb-server/src/main/java/com/fumbbl/ffb/server/team/bb2025/SkillDefinitions.java); construction checks every entry against the BB2025 native skill factory.

Current catalog `bb2025-human-2026-09-25.1` includes all 108. Skills are purchasable only when the position has category access, lacks the skill already, and meets the source's prerequisites and conflicts. Traits are never purchasable. Of the 72 skills, 59 have a legal Human recipient. No Human position has Mutation access, and none has the Secret Weapon trait required for Saboteur. The builder filters those cases as a choice hint; the server remains the authority. The existing Human roster, values, preset and artwork are unchanged. Orc roster activation is separate.

Three native BB2025 category corrections were required: Hit and Run is Agility, Steady Footing is General, and Bloodlust is a Trait. Bloodlust now has a BB2025 class while BB2020 keeps its earlier class and category. The category corrections do not establish effect-level parity with the source. In particular, parameterized traits such as Bloodlust, Animosity, Hatred and Loner require explicit roster values and frozen-team conversion checks before future positions use them.

The server maps stable IDs to native skills when a team is frozen for a match. The two earlier Human catalog versions remain readable in frozen match records and result metadata. The current roster does not grant a new trait to any player. Account saved teams may be cleared at activation under the owner's authorization; no account data has been cleared here.

Reference constraints checked for purchases: Lethal Flight requires Right Stuff; Saboteur requires Secret Weapon; Bullseye and Strong Arm require Throw Team-Mate; Leap conflicts with Pogo; Frenzy conflicts with Grab, Hit and Run, Multiple Block and Ball & Chain; Ball & Chain excludes the further skills listed in the source.

Verification includes a 108-entry factory/category test, all 59 Human-legal single purchases through draft validation and frozen conversion, negative prerequisite cases, historical frozen-match loading, and explicit browser catalog and two-team prepared-match size checks. The final focused Java run passed 39 tests; the full offline eight-module Maven build passed. The browser suite passed 68 tests, browser and site builds passed, the team-request schema accepted one valid and rejected ten invalid examples, and the signed-in builder save/select browser test and four site client tests passed. Controlled match scenarios for every newly selectable skill and future roster trait remain release validation work.
