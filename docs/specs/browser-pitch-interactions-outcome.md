# Browser pitch interactions: outcome

2026-09-29. Review against the [agreed browser pitch interactions](browser-pitch-interactions.md). All three issues are closed and their work is merged: [smart actions #95](https://github.com/the-grognard-codes/fumbbl-rebuild/pull/95), [setup dragging #96](https://github.com/the-grognard-codes/fumbbl-rebuild/pull/96), and [pitch pushback #97](https://github.com/the-grognard-codes/fumbbl-rebuild/pull/97). Each PR passed its required checks before merge. Merges to `main` trigger the configured DEV Hosting delivery workflow; this review does not claim a signed-in DEV match was played.

The final browser unit run passed **113 tests**. The hosted and main browser bundles built. The site browser suite passed **10 tests**; Static delivery on [#97](https://github.com/the-grognard-codes/fumbbl-rebuild/pull/97) also ran the setup and push interaction scripts. The outcome report adds the slice 1 smart-click script to that same CI command, so all three interaction scripts will be checked on subsequent changes.

The implementation follows the agreed behavior. During delivery, direct adjacent move selection and older action projections were preserved, and incomplete push projections keep the existing modal so the coach can still choose. These are compatibility cases, not scope changes.

**Acceptance limit:** the browser interaction tests use mocked transport with server-issued fixture projections. No signed-in two-coach match on DEV was run for these changes, and touch dragging was not exercised. The existing [integrated match acceptance issue #53](https://github.com/the-grognard-codes/fumbbl-rebuild/issues/53) remains the place for that live review. No known feature gap remains in the three requested slices.
