# Preview typography

The MVP uses Alegreya SC Medium (500) and Bold (700) for scoreboard and display
type, with Barlow Semi Condensed Regular (400) for details, controls and chat.
Alegreya SC is a visual approximation of the concept's lettering; the exact
reference font is not identified.

Both families are served locally. Sources are the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/alegreyasc
- https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed

The original SIL Open Font License texts are included beside the font files.
# MUTP match HUD

The coach-oriented HUD uses this same face. The [upstream license](https://github.com/google/fonts/blob/main/ofl/chakrapetch/OFL.txt) is included as `ChakraPetch-OFL.txt`.
